# Glossário rápido

| Termo | Significado |
| --- | --- |
| Algoritmo | sequência finita de passos para resolver um problema |
| Array | estrutura de tamanho fixo que armazena valores do mesmo tipo |
| Argumento | valor enviado ao chamar um método |
| Classe | modelo que define dados e comportamentos de objetos |
| Compilação | transformação do código-fonte para uma forma executável pela JVM |
| Condição | expressão cujo resultado é verdadeiro ou falso |
| IDE | programa que reúne editor, execução, depuração e outras ferramentas |
| Índice | posição de um elemento em um vetor; começa em zero |
| Iteração | uma execução de um laço de repetição |
| JVM | máquina virtual que executa o bytecode Java |
| Método | bloco nomeado que executa uma responsabilidade |
| Objeto | ocorrência concreta criada a partir de uma classe |
| Parâmetro | variável declarada para receber um valor em um método |
| POO | forma de organizar programas por objetos que reúnem estado e comportamento |
| Refatoração | melhoria da estrutura interna sem alterar o comportamento esperado |
| Variável | espaço nomeado usado para guardar um valor |
